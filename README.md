# **Saathi ChatBot**
Saathi is an intelligent conversational chatbot designed to provide emotional support, sentiment understanding, and crisis detection. It integrates natural language processing, multilingual capabilities, and a database-backed chat history system to deliver meaningful interactions.

# **Features**
**Conversational AI** – Handles user queries and engages in natural dialogue
**Sentiment Analysis** – Detects emotional tone from user inputs
**Crisis Detection** – Identifies high-risk or distress signals in conversations
**Multilingual Support** – Translates user input for broader accessibility
**Chat History Storage** – Maintains conversation logs using a database
**Consultant Integration** – Connects users with support resources
**External AI Integration** – Uses Gemini API for enhanced responses
